# The Clinical Brain and the Board Exam Pain 🧠⚡

A bright, ADHD-friendly interactive NCMHCE study app.

## What is in it
- Smart 10: weights questions you have missed or felt unsure about
- Lightning Round
- Ethics Hot Seat
- Diagnosis Duel
- Treatment Match
- Clinical Case Arcade with 23 original full cases built as Intake → Session 1 → Session 2, with 9 questions per case
- 228 full-case questions + 40 rapid-practice questions (268 original items total)
- Missed-question bank
- Confidence tracking
- Domain-level progress dashboard
- Visual memory rules
- Local browser progress (no login/database required)

## Exam focus
This project is currently optimized for the **current NCMHCE format used before July 1, 2027**. The interface still contains a future-profile reference switch, but the full case bank is written to rehearse the current three-part case-study structure.

The practice items in this repository are **original study questions**, not copied or released NBCC examination questions.

## Sources used for structure
The study design is aligned to official NBCC public materials for the NCMHCE, including the current content outline and the examination specifications effective July 1, 2027. Always check NBCC for the latest exam specifications before testing.

## Run locally
Open `index.html` in a browser. No build step is required.

## GitHub Pages
Because the app is static, it can be hosted directly with GitHub Pages from the repository root on the `main` branch:
1. Repository **Settings**
2. **Pages**
3. Source: **Deploy from a branch**
4. Branch: **main** / **root**
5. Save

Progress is stored in browser localStorage, so it stays on the device/browser where you study.

## Disclaimer
Educational exam-prep tool only. It is not an official NBCC product, a substitute for the DSM-5-TR or ACA Code of Ethics, legal advice, clinical supervision, or a source of state-specific law.
